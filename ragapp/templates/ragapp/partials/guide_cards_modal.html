1/7

🔎 웹 검색

  1. 질문 적으면 웹에서 찾아서 짧게 정리해줘
  2. 필요한 경우에는 밑에 참고 링크(출처)도 같이 붙여줄 거야
  3. 처음이면 짧게 한 문장으로 물어봐도 충분해
  4. 오류/품질 개선을 위해 일부 내용이 일시적으로 기록될 수 있어
  1. 주소/전화/주민번호 같은 건 입력하지 말자
  2. 민감한 내용은 그냥 빼고 물어보는 게 안전해
사용 가이드
2/7

🧠 AI 요약 검색

  1. 서버에 저장된 요약/링크를 참고해서 답해줘
  2. 관련 근거도 원하면 같이 보여줄 수 있어
  3. 같은 주제는 쌓일수록 더 빨라지고 더 정확해져
  4. 오류/품질 개선을 위해 일부 내용이 일시적으로 기록될 수 있어
  1. 중요한 건 원문(출처) 한번만 꼭 확인해줘
사용 가이드
3/7

📤 파일 올려서 분석하기

  1. 파일을 업로드해야 분석이 시작돼
  2. 지원: PDF/TXT · 이미지
  3. 올리면 요약/핵심 추출/정리를 해줄게
  4. 큰 파일은 나눠 올리면 더 안정적이야
  1. 개인정보 들어간 파일은 업로드하지 말자
  2. 저작권/비공개 자료도 가능한 한 피하는 게 좋아
사용 가이드
4/7

🔗 출처 확인하는 법

  1. 요약 아래쪽 “참고 링크”가 출처야
  2. 여러 개면 위에서부터 하나씩 보면 돼
  3. 핵심 판단은 원문이 제일 정확해
  4. 헷갈리면 다른 모드로 한 번 더 교차 확인해봐
  1. 답변은 참고용! 최종 판단은 네가 하는 거야
사용 가이드
5/7

📝 게시판: 기록/피드백 남기기

  1. 테스트하면서 느낀 점/버그를 남길 수 있어
  2. 글/댓글은 비밀번호로 관리할 수 있어
  3. 신고/차단 같은 기본 운영 기능도 있어
  4. 불편한 거 있으면 게시판에 적어주면 제일 빨라
  1. 개인정보/욕설/저작권 문제 되는 내용은 올리지 말자
  2. 문제 글은 운영 기준에 따라 정리될 수 있어
사용 가이드
6/7

💬 문의/상담

  1. 쓰다가 막히는 거 있으면 편하게 물어봐
  2. 운영자가 확인하고 답해줄 수 있어
  3. 개선하려고 최소한의 기록이 남을 수 있어
  4. 긴 얘기는 핵심만 짧게 적어주면 더 정확해져
  1. 계좌/주소/주민번호 같은 건 절대 적지 말자

⚡ Quick Tools(바로가기)

  1. 이미지는 Quick Tools에서 바로 들어갈 수 있어
  2. 추천 흐름: 업로드 → 찾아보기(확인/활용)
  3. 부적절한 업로드는 제한될 수 있어(그건 어쩔 수 없음)
  4. 개인정보 들어간 이미지는 업로드하지 말자
