📘 PDF 분석 사용 설명서

이 기능은 PDF 파일 안의 내용을 AI에게 맡겨 요약하거나 표 형식으로 정리해 주는 기능이에요.

  1. PDF 파일 선택에서 리포트·과제·계약서 등 분석할 파일을 고릅니다.
  2. 질문 입력 칸에 “핵심만 5줄로 요약해줘”, “과목별 점수만 표로 정리해줘”처럼 원하는 지시를 적어 주세요.
  3. 출력 형식에서 일반 요약 또는 표로 정리를 고른 뒤 PDF 분석하기 버튼을 누르면 결과가 아래 박스에 표시됩니다.
  4. 다시 분석하고 싶으면 질문이나 출력 형식을 바꾼 뒤, 같은 버튼을 한 번 더 눌러 주면 됩니다.

실제 PDF 파일 자체는 서버에 오래 보관하지 않고, 결과·로그 처리 방식은 화면 아래 개인정보처리방침을 참고해 주세요.
