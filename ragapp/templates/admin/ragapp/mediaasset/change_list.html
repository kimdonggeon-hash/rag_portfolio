    미디어 자산 검색

    관리자가 등록한 이미지·PDF·문서 파일을 한곳에서 보관하고 이름과 설명으로 다시 찾는 파일 자료실입니다.
    📘 미디어 자산 사용 설명서
    1. MEDIA ASSET 추가를 눌러 파일을 선택하고, 나중에 찾기 쉬운 설명을 caption에 입력합니다.
    2. 검색창에서는 파일명과 caption의 일부만 입력해도 찾을 수 있습니다. 예: 제품 로고, .pdf
    3. 오른쪽 필터에서 파일 형식·AI 검색 상태를 조합해 결과를 좁히고, 특정 날짜만 보려면 목록 위쪽의 날짜 이동을 사용합니다.
    4. AI 유사 이미지 검색은 이미지 검수·승인 과정에서 벡터DB에 등록된 이미지 중 의미가 비슷한 자료를 찾습니다.
    5. 파일을 추가하면 MIME 형식, 용량, SHA-256 해시는 자동으로 기록됩니다.
    일반 검색과 AI 검색의 차이
    일반 검색은 파일명·설명에 실제로 포함된 글자를 찾고, AI 검색은 “노을 바다 풍경”처럼 의미가 비슷한 이미지를 찾습니다. 목록이 0건이면 오류가 아니라 아직 이 자료실에 직접 등록한 파일이 없다는 뜻입니다.
